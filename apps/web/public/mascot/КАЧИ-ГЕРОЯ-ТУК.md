# Героят

Имаш два начина.

## Лесният: качи целия лист и пусни един скрипт

Сложи листа с осемте фигури където и да е и пусни:

    node scripts/split-mascot.mjs пътят/до/листа.png

Скриптът реже листа на осем, маха надписите отдолу, маха белия фон
(само свързания с ръба — белите парчета по топката и каретата на
шапката остават) и записва осемте файла тук.

## Ръчният: осем файла с прозрачен фон

    apps/web/public/mascot/empty.png     сивият, умърлушен      → 0 кредита
    apps/web/public/mascot/low.png       бледият, спокоен       → 1–4
    apps/web/public/mascot/happy.png     лаймът, усмихнат       → 5–14
    apps/web/public/mascot/full.png      лаймът с каре и искри  → 15+
    apps/web/public/mascot/stale.png     синият, нацупен        → 7+ дни без употреба
    apps/web/public/mascot/working.png   лилавият, затворени очи → докато генерира
    apps/web/public/mascot/done.png      тъмният, радостен      → успех
    apps/web/public/mascot/failed.png    сивият, разплакан      → грешка

Квадратни, 512×512, прозрачен фон.

Праговете се сменят на едно място: `MOOD_THRESHOLDS` в
`apps/web/components/mascot.tsx`.
